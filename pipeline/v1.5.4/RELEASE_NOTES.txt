ARF release 1.5.4 (23 October 2026): the dense-constellation arm (protocol amendment A3)
=====================================================================================
What it is
  An exploratory arm beside the confirmatory real-fleet protocol. The Starlink orbital geometry stands
  in for a hypothetical dense Earth-observation constellation, at fleet sizes the real fleets do not
  reach. Starlink carries no imaging payload: every imaging parameter of the arm is an ASSUMPTION
  (off-nadir half-angle 9.22 deg, the proxy default since the earliest runs; daylight limit, sun at
  least 5 deg at the imaged point, the Landsat criterion also assumed for Sentinel-2). No hypothesis
  decision is drawn from the arm; it is reported descriptively.

  The real-fleet protocol is unchanged: release of record 1.5.3 (SHA-256 14426c89c916ffcaac032cb94ec186ef7a7f8011748044c99f2386585d917950),
  its designs, hypotheses, windows and rules. Amendment A3 was recorded before the confirmatory
  analysis was run.

The arm (27 runs, batch exploratory_v154_dense; CKGR + Okavango Delta; every protocol setting except
the cloud-sensitivity sweep, which is off)
  window of 3 August 2026      N = 100, 500, 1000, 2000, 4000, 8000   (scaling over N)
  windows 10 Aug - 21 Sep      N = 100, 500, 1000                     (spread across windows)
  The satellites operational at the window start, in one seeded random order: a fleet of size N is the
  first N, so each smaller fleet is contained in each larger one. N = 8000 runs last.

Tested here, and what is not
  Tested: every option of Cell 0; Cells 0-9 of the proxy end to end with real Orekit on 10,084
  synthetic Starlink-like satellites (operational filter, nesting of N, daylight limit, folder tags,
  manifest); the batch list; the audit (planted faults caught); the launch cell on a mock Drive (1.5.3
  untouched, parity 5/5 MATCH, guards against a wrong release or a protocol without A3).
  NOT tested: the live Space-Track query of the arm (this sandbox cannot reach Space-Track). It uses
  the documented REST form, including /predicates/ (as built by the spacetrack client 2.1.0); if it
  fails, the first run stops with Space-Track's message and nothing else is affected.
